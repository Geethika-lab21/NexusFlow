# NexusFlow Security & Compliance

## Security Standards & Certifications

### Certifications
- **SOC 2 Type II Certified**: Audited by independent third-party CPA firms covering Security, Availability, and Confidentiality trust principles.
- **ISO/IEC 27001 Aligned**: Information security management systems mapped to global standard frameworks.

### Privacy & Data Protection
- **GDPR & CCPA Compliant**: Built-in data subject request (DSR) workflows for right-to-erasure and right-to-access. Standard Data Processing Addendum (DPA) available.
- **Zero Data Training Policy**: Customer data is never utilized to train generic third-party foundational LLMs without explicit enterprise opt-in.

### Encryption & Network Security
- **Data in Transit**: TLS 1.3 enforced for all web dashboard and REST API communications with forward secrecy.
- **Data at Rest**: AES-256 bit encryption applied across all databases, vector indices, and S3 object storage backups.
- **Key Management**: Optional Bring-Your-Own-Key (BYOK) via AWS KMS or HashiCorp Vault for Enterprise accounts.
- **Vulnerability Scanning**: Continuous automated container scanning and annual third-party penetration testing.
